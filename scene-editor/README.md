# DELTARUNE 场景编辑器 V1.0

在本机制作可试玩的场景、横版地下城、赛车和宣传片，或将场景接入独立战斗编辑器。V1.0 可独立启动，支持插件、素材管理与单文件离线 HTML 导出。发布包提供程序和自带示例，官方素材通过设置另行配置。

## 快速开始

1. 解压发布包，安装 Python 3.11 或更新版本与 Pillow。要保存工程、安装插件或使用战斗打包，请安装 Node.js。
2. 双击 [launch-v1.cmd](launch-v1.cmd)，打开本机编辑器。首次启动可自动检测或手工填写素材目录，保存后重启。
3. 打开「回声工坊」试用，或点「新建」。用「试玩」调试，再用「离线 HTML」导出可分享的试玩文件。
