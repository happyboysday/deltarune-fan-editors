### 浏览器环境待复验

四项浏览器测试均在启动隔离服务器并连接 Edge 后中断。独立的空白页探针在第一条 `Page.enable` 指令时复现了断线，Edge 日志显示 GPU 子进程反复以 `0xC0000022` 退出，最终报 `GPU process isn't usable`。迁移后的场景工程在 Node 和 Python 的服务器探测中均可通过 HTTP 读取，关闭方法也已验证。完整浏览器断言需在 Edge 可以正常启动子进程的环境中复跑。
