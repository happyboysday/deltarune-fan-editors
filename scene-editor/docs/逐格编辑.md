# 逐格编辑 · 像搭积木一样做房间

工作台把房间看成一张格子地图：在右边选一个零件，在画布的格子上点或拖，就放下去。保存出来仍是普通的 `deltarune-scene/1` 工程，试玩、离线 HTML 和复放都不用改。

同一张格子地图也能写成**文字地图**，一格一个字符，AI 和需要整片修改的人可以直接读写。

## 在工作台里

| 操作 | 方法 |
|---|---|
| 选零件 | 右边「逐格摆放」的零件盘；数字键 1–9、0 对应前十个 |
| 放置 | 画笔（B）：点一下放一个，按住拖动连续放 |
| 擦除 | 右键随时擦；或橡皮（E）点、拖 |
| 整片填 | 矩形（R）拖出范围。地形填满；触发区变成一整块；其他物件按自己的大小铺满 |
| 选中、搬动 | 选择（V）点物件，拖到别的格子；方向键一次挪一格；Delete 删除；Esc 取消 |
| 移动画面 | 滚轮上下、Shift＋滚轮左右；中键拖动，或按住空格拖动；没选中物件时方向键也能移动画面 |
| 撤销、重做 | Ctrl+Z、Ctrl+Y（或 Ctrl+Shift+Z），最多 60 步 |
| 网格线 | G 开关 |
| 每格多大 | 左边「每格」，每个房间单独设（8–64 像素，默认 20） |

放下一个物件（不是墙这类地形）后会自动选中它，右边检查器可以马上填名字、绑事件、改「占几格宽 / 高」。

状态栏右边显示鼠标所在的格子、像素位置和格子里的东西。

**吸附格子**默认打开。关掉以后，画笔和矩形回到旧的自由拖矩形方式，可以放任意像素大小的物件。

### 零件

| 符号 | 零件 | 说明 |
|---|---|---|
| `#` | 墙 | 连成一片的墙存档时自动合并成最少的矩形 |
| `-` | 单向平台 | 横版跳跃房间里只挡住向下落地 |
| `~` | 滑行区 | 冰面 |
| `=` | 攀爬区 | |
| `@` | 入口 | 进入房间时玩家站的格子 |
| `N` `E` `D` `B` | NPC、敌人、门、推块 | 门默认占 1×2 格 |
| `S` `C` `P` | 踏板、检查点、存档点 | |
| `O` `Z` `K` | 物件、触发区、长按机关 | |

前四种是**地形**：画在格子底层，连片合并。其余是**物件**：每个都有自己的 ID、名字和事件，搬动、改大小都会保留。物件放在墙上时，会把底下的墙挖开（门嵌进墙里就是这样做的）。

### 大素材：自定义零件和占格

导入的大图（长椅、大桌子、整面货架）可以做成**自定义零件**：

1. 零件盘最后点「＋ 自定义零件」。
2. 选工程里已有的图片，或「导入新图片…」。
3. 工作台按图片像素和每格大小算出建议占格（例如 80×24 像素、每格 20，建议 4×2）。可以改成你要的，长椅一般 4×1。
4. 填名称、文字地图里的字母、种类（物件、NPC、墙……）、能否穿过。

之后它就和内置零件一样在零件盘里，画笔点一下放一整张长椅。双击零件盘里的自定义零件可以修改或删除。

已经放下的物件，在检查器的「占几格宽 / 高」改大小，左上角不动。只想临时放一个大一点的，也可以改零件盘下面的「占格」，再点「默认」恢复。

自定义零件存在工程的 `gridParts` 里，同一个工程的所有房间共用：

```json
"gridParts": {
  "part_1": {"sym": "L", "label": "长椅", "kind": "prop", "sprite": "bench", "cells": [4, 1], "props": {"solid": true}}
}
```

用了这个素材的同种物件会被认成这个零件。字母只能用内置没用过的大写字母：A F G H I J L M Q R T U V W X Y，最多 16 个。

### 旧物件

从官方房间导入的碰撞、手动拖出的不对齐矩形，没有对齐格子，在画布上是**虚线框**，文字地图里显示为 `?`。

- 画笔不会覆盖它们。
- 橡皮或右键可以删掉。
- 选择工具可以按像素拖动它们。

## 文字地图（给 AI，也给喜欢精确的人）

中间「文字地图」面板会显示当前房间。改完按「应用到当前房间」，按 Ctrl+Z 可以撤回。

```
; 房间 hall · 16×8 格 · 每格 20 像素 · 房间 320×160 像素
################  ; 0
#..@......N....#  ; 1
#..........~~~.#  ; 2
#..Zzz.....~~~.D  ; 3
#..zzz.....~~~.d  ; 4
#......B..S....#  ; 5
#..Llll........#  ; 6
#####----#######  ; 7
```

规则：

- 一行就是一排格子，行数、每行字符数要和房间一样。行首的 `;` 和每行空格后面的内容都是注释。
- 物件在左上角写**大写**字母，同一个物件占的其余格子写**同一个字母的小写**。上例中 `Zzz/zzz` 是一个 3×2 的触发区，`D/d` 是一扇 1×2 的门，`Llll` 是一张 4×1 的长椅。
- 已有物件按「同一种零件、同一个左上角」认回来，保留 ID、名字、事件和所有属性。
- 某种零件挪了位置（数量不变），也按阅读顺序认回来，名字和事件跟着走。
- `?` 原样保留；要改那些旧物件请用编辑器或工程 JSON。
- 文字地图只管位置和大小。名字、对白、事件、门通向哪里，还是在检查器或工程 JSON 里写。
- 写错时会指出第几行第几列、错在哪里。

### 命令行

在场景编辑器目录下：

```powershell
node tools/scene.mjs parts 工程.json                      # 零件表（含这个工程的自定义零件）
node tools/scene.mjs grid show 工程.json hall              # 打印房间 hall 的文字地图
node tools/scene.mjs grid apply 工程.json hall 地图.txt    # 只检查，不写文件
node tools/scene.mjs grid apply 工程.json hall 地图.txt --write
node tools/scene.mjs grid new 工程.json cave 地图.txt --title 洞穴 --size 20 --write
node tools/scene.mjs init 新工程.json 地图.txt --title 我的场景   # 一张地图建整个工程
node tools/verify-grid.mjs                                 # 逐格编辑回归检查
```

`apply`、`new` 会先校验整个工程。校验不过就不写文件，并列出错误和提醒。地图文件写 `-` 表示从标准输入读。

### 给 AI 的建议流程

1. `parts` 看零件表，`grid show` 读房间。
2. 改文字地图（或照规则写一张新的），用 `grid apply … --write` 或 `grid new`。
3. 在工程 JSON 里给物件补 `name`、`event`、门的 `room` / `entry`，以及 `events` 里的对白。
4. `node tools/scene.mjs validate 工程.json`，零错误后在工作台试玩。

## 地下城工作台

顶部「横版地下城」可打开官方素材示例，也可访问 `/?project=/examples/dungeon-demo.scene.json`。要转换自己的房间，在「逐格摆放」点「切换为地下城房间」。这个按钮保留现有房间，设置 `mode: "dungeon"` 并补齐横版移动默认值。在「角色动作与敌人类型」中可为本房间选择角色。选择默认项时沿用 `project.player.fighter`，工程也未指定时使用内置 Kris。

| 编辑图层 | 文字地图参数 | 放置内容 |
|---|---|---|
| 碰撞 | `collision` | 墙、单向平台和移动区 |
| 背景 | `back` | 角色后面的方块 |
| 同层 | `actor` | 与物件、角色按底边 Y 加深度排序的方块 |
| 前景 | `front` | 始终遮挡角色的方块，画布以紫色虚线标边 |
| 敌人与物件 | `objects` | 敌人类型、自定义物件、内置物件与入口 |

选图层后，调色盘、数字快捷键、画笔、右键橡皮、矩形和文字地图都跟随当前层。地下城画笔始终吸附网格。同一格可以放背景、实体平台、前景和敌人。其他层半透明，可勾选「只看当前层」。实体平台在方块定义的「碰撞」里选实体或单向即可。

### 方块

「新建方块零件」可直接选工程图片或导入文件。「从官方瓦片集新建方块」打开第 5 章瓦片图，可点一格、拖选矩形，或输入起始行列和宽高。裁剪会逐格去掉瓦片边界，再把选区拼成图片。默认占格为图片宽高分别除以当前格子尺寸并向上取整。例如，40×80 像素的区域在 20 像素网格上占 2×4 格。可手调占格、层、碰撞和深度，保存后即可在对应层使用。瓦片集有官方预设时，也可整组导入。

方块定义存入 `project.tileParts`，使用自动分配的小写字母或数字。实例在 `room.tiles` 中引用零件 ID。旧 `sprite` 方块根据 `front` 分层，文字地图中显示为 `?`。没有对齐或同层重叠的旧方块也会锁定，以保留原像素位置和叠放顺序。

### 动作、技能和敌人

1. 在「角色动作与敌人类型」中点「新建角色」，或从官方 Kris 预设开始。既有角色可在房间角色列表中选中，再点「编辑角色动作」。
2. 在动作槽中切换待机、移动、受伤、攻击等状态。可选工程素材、从官方第 5 章动画库选整组帧，或一次选择多张图片导入。文件按名称中的数字排序。预览支持每帧 tick、循环、暂停、下一帧和朝向切换。
3. 选攻击段或空中攻击。调整前摇、生效、后摇，在预览上拖动矩形设定攻击框。金色点是脚底原点，背景每格代表 40 房间像素。「素材朝向与脚底偏移」里的 X、Y 使用原生像素，随素材倍率（0.25–8）放大。判定框直接使用房间像素。视图倍率只调整观察大小。朝左拖出的框会换算成朝右坐标写回。地面攻击可增加、删除、前移和后移。
4. 「＋ 技能」分配空闲的技能键。选择飞射、范围、弹反、突进或治疗后，填写对应的参数。动画时序以 30 Hz 的 tick 表示，技能冷却与射击间隔以秒表示。
5. 新建敌人类型，设定动画、AI、HP、接触伤害和占格。按需要开启近战或射击，再填写参数。大写地图符号与内置物件和 `gridParts` 共用。保存后切到「敌人与物件」摆放。
6. 对话框内的编辑在「保存」时一起应用，可整步撤销。官方预设未载入时仍可通过官方动画目录和瓦片选区手工制作。

### 分层文字地图与 CLI

```powershell
node tools/scene.mjs dungeon init 工程.json cave --cols 32 --rows 24 --size 20 --out 地下城.json
node tools/scene.mjs parts 地下城.json
node tools/scene.mjs grid show 地下城.json cave --layer back
node tools/scene.mjs grid apply 地下城.json cave 背景.txt --layer back --write
node tools/scene.mjs grid show 地下城.json cave --layer objects
```

`dungeon init` 生成地面、左右墙和一个可进入的区域。指定已有房间名会重新生成该房间，并保留其入口名称。和 `grid apply` 一样，省略 `--write` 和 `--out` 时仅校验。工作台的转换按钮适合保留已有布景。

不带 `--layer` 的 `show/apply` 沿用碰撞与物件的合并地图。分层地图里的 `.` 只清空当前层。方块的每一格都写同一符号，例如占 2×1 的 `a` 连放两个写成 `aaaa`。读取时先认回同位置实例，再按占格从左到右、从上到下拆开。新布置的多格方块必须写完整。敌人仍在左上格写大写、其余占格写小写。图层覆盖、深度、出现条件以及敌人实例的 HP 等字段随认回的实例保留。
