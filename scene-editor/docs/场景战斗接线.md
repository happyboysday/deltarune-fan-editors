
# 场景与战斗接线 · V1.0

用 `launch-v1.cmd` 启动编辑器。上方切换到《纸门值班室》后可直接试玩。向上找值班员按 Z，选择按铃。也可以向右走、接触折纸哨兵。战斗里可击败它，或 ACT 盖章、躲过一轮后再用 SPARE。战斗菜单里按 X 可以逃离这场示例。击败和饶恕会打开同一扇门，档案与获得的道具不同。

1. 点「战斗编辑器」打开整合工作区。用原来的遭遇、攻击、素材和作品包工具制作，先把遭遇保存到工作区。
2. 在场景编辑器「遭遇战与结算」刷新目录，新建引用，选择场景工作区、作品目录或内置样例中的遭遇。为需要的结果绑定场景事件。工作区遭遇可以直接点「编辑遭遇」打开；内置样例要修改时，先另存到工作区，再把引用改为新文件。
3. 要接触触发，就在画布放「敌人」，在检查器选择「遭遇战」；要从对白触发，就在「事件与演出」选「对白后开战」模板，或在对白、选项、条件分支后插入 `battle` 指令。
4. 「校验工程」会检查场景事件、战斗文件和弹幕资源；「试玩」使用启动时最新保存的遭遇。保存了新的战斗改动，回到编辑再点「试玩」即可加载。导出「离线 HTML」会在一个文件内打包场景、遭遇、弹幕和素材。

## 工程字段

```json
{
  "battles": {
    "guard": {
      "encounter": "paper-guard",
      "source": "workspace",
      "lang": "zh",
      "resultFlag": "guard_result",
      "on": {
        "victory": "after_defeat_enemy",
        "spared": "after_mercy",
        "defeat": "after_party_lost",
        "flee": "after_escape"
      }
    }
  }
}
```

- `encounter` 是战斗文件名（去掉 .json）；`source` 默认为 `workspace`，可用 `sample` 固定指向内置样例。选择作品库会生成 `{"source":"project","work":"作品目录","encounter":"遭遇文件名"}`。每个目录各自解析遭遇、攻击与自定义素材，同名文件可以同时使用。`lang` 默认为 `zh`。
- `on` 的值是场景事件 ID。省略分支就直接返回；`resultFlag` 可选，写入 `victory`、`spared`、`defeat` 或 `flee`。其中 `defeat` 指玩家队伍落败。
- 事件指令为 `{"op":"battle","battle":"guard"}`。战斗结算后先执行绑定的分支，再执行这条指令后面的内容。分支主动转房间、回检查点等情况按场景原有规则处理。
- 敌人物件用 `{"id":"guard_npc","kind":"enemy","x":307,"y":141,"w":28,"h":34,"battle":"guard","auto":true,"once":true}`。接触时可先执行物件的 `event`，再进入战斗。`auto:false` 改为按 Z。接触型不宜设为固体。设 `once:true` 时，胜利或饶恕后停用这次接触；要隐藏或改变敌人的样子，可在结果分支用旗标、`show` 或 `sprite`。队伍落败、逃离或资源错误不会把遭遇记作已完成。
- 返回后会保留场景中的房间、坐标、朝向和镜头；战斗期间场景计时暂停，入战和返回时清掉跨界面按住的键。留在敌人接触区不会马上二次开战，要先离开再回来。未启用共享时，HP、TP 和道具仍按每场遭遇配置。要同步队伍和库存、分结果发奖励或设置存档点，请读 [队伍、试玩存档与入战演出](队伍存档与转场.md)。
- 工程 JSON 保存的是引用。给其他作者分享可编辑工程时，另外用原战斗编辑器的「作品包」带上自定义遭遇、弹幕与素材。只分享试玩则给离线 HTML 即可。

## 路径与验证

默认工作区在数据目录的 `battle-workspace/`。启动时只写入缺失的样例遭遇及攻击。用 `launch-v1.cmd --battle-works "工作区路径"` 接入已有工作区，示例原稿位于 `examples/battle/`。可在设置页配置战斗编辑器，也可用 `--battle-root` 指向程序目录。默认作品库为战斗编辑器的 `works/`，可用 `--battle-library "作品库路径"` 指定其他作品集。场景和战斗都只监听本机。

```powershell
node tools/scene.mjs validate examples/paper-gate.scene.json
node tools/scene.mjs replay examples/paper-gate.scene.json examples/paper-gate.replay.json
node tools/verify-battle.mjs "新版战斗编辑器路径"
```

CLI 场景复放可在一段输入结束时注入已知结算，例如 `{"n":1,"battle":"guard","battleResult":"spared"}`。这用于单独验证剧情；`verify-battle.mjs` 使用真实战斗引擎走四条路线，检查实际菜单、碰撞和结算。浏览器验收另验证正常按键、旧编辑器保存、离线资源和战斗音乐释放。
