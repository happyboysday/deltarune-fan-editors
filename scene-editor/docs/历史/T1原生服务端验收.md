# T1 原生服务端验收

2026-11-21，分支 `v1.0/t1-server`，基于 T0 的 `cc3a7bb`。不传 `--base` 可以启动场景编辑器。配置官方数据后，可以导入房间、打开第 5 章和地下城示例、保存使用自定义素材的工程并导出离线 HTML。Edge 界面验收仍需在沙盒外复测。

## 文件与接口

| 文件 | 改动 |
| --- | --- |
| `studio_server.py`、`studio_core/http.py` | 回环监听、请求分派、Host／Origin／Fetch Metadata 检查、HEAD、JSON、静态文件、路径检查与额外路由注册 |
| `studio_core/a_assets.py`、`official.py`、`origin_overlay.py`、`placement_overlay.py`、`visibility_overlay.py` | 读取 A-export v8、校验配套校正资料、按需裁切 tile，提供 `/api/a/rooms`、房间详情、`/a-files/` 和 `/official/` |
| `studio_core/custom_assets.py`、`sequence_assets.py`、`user_assets.py`、`registry_io.py` | 接管 `/api/assets/resolve`、`/api/custom-assets`、`/api/animations`、`/api/animations/import` 及两种图片 URL。写入时先发布 PNG，再发布登记，同一章的并发导入受文件锁保护 |
| `studio_core/layout.py`、`studio/index.html` | 传入 `--base` 时启用旧工作台页面、脚本、依赖接口和交接。省略时隐藏入口，直接打开 `/layout/` 可见中文说明 |
| `ui_assets.py`、`chapter_host.py`、`chapter_navigation.py` | 音效、章节修改、生成物和试玩副本写入数据目录。章节可复用源素材中版本匹配的预构建副本 |
| `tools/test-native-server.mjs`、`test-all.mjs`、`test-env.mjs`、`test_env.py`、`verify-navigator-ui.py`、`README.md` | 原生服务回归、V0.6 对照、独立数据目录测试、参数表和启动示例 |

T2 可在启动时传入 `start(args, extra_routes=[provider])`，也可在开始监听请求前向 `server.extra_routes` 追加函数。调用签名为 `provider(method, path, query, body, head_only)`。方法保留 GET、HEAD 或 POST，路径保留 URL 编码，查询值为字符串列表。读请求的 body 是 `None`，POST 的 body 是解码后的 JSON。返回 `None` 会尝试下一个函数，返回 `studio_core.http.Response` 会结束分派。测试用两个提供者验证了依次匹配、重复查询参数、JSON 请求体和 HEAD 响应长度。

## 测试结果

使用 Node.js 26.13.0、Python 3.12.14、Pillow 13.0.0。按 T0 基线设置了 `PYTHON`。测试从 `tools/test-env.local.json` 读取真实数据路径，将工程和 V0.6 参照程序复制到 `.codex-tmp/`。V0.6 和 V1.0 分别写入自己的临时目录。

| 命令 | PASS | FAIL | SKIP | 结果 |
| --- | ---: | ---: | ---: | --- |
| `node tools/test-native-server.mjs` | 1 | 0 | 0 | 41 项 V0.6 响应对比，以及下列原生流程检查全部通过 |
| `node tools/test-all.mjs` | 14 | 0 | 10 | 比 T0 多通过一项 |
| `node tools/test-all.mjs --browser` | 14 | 4 | 6 | 与 T0 沙盒基线相同的四项浏览器测试发生 CDP 断线 |
| `node tools/test-native-server.mjs --browser` | 0 | 1 | 0 | 接口检查通过；Edge 在第一条 `Page.enable` 期间断线，尚未执行页面断言 |

1. **官方房间与文件**。对照两台服务的五章目录、11 个房间的完整详情、两章现切 tile、官方 PNG、A-export JSON 和 UI 文件（含菜单音效）。对比状态码、Content-Type、解析后的完整 JSON 或文件字节。另用只含数据的便携目录启动，验证了默认 `a-export/` 的目录发现与海滩房间完整响应。
2. **自定义素材和序列**。两台服务各导入同一 PNG，以及两张尺寸不同、文件名为 `f10.png` 和 `f2.png` 的帧。检查自然排序、显式排序、别名、列表、混合 ID 解析和图片读取。新旧服务生成的 PNG 与磁盘登记 JSON 逐字节一致。另测两个进程对同一序列添加别名，以及从两个旧位置读取、重新登记时保留原件和旧别名。
3. **原生编辑与导出**。读取首页、第 5 章的 196 个房间和起点分层资源，验证地下城工程和动画目录。获取海滩地图和提示，加入已上传素材，保存工程并按修订号读回。使用前端实际的 `prepareArt`、`packArt`、`makeHtml` 打包，检查地图绘制数据、上传 PNG 的内嵌字节、UI 素材和播放器模块。生成的离线 HTML 为 6,397,619 字节。此项验证了打包产物，浏览器播放尚待复测。
4. **权限、写入与降级**。覆盖 Host、Origin、Fetch Metadata、私有图片、HEAD 和路径边界。官方数据全缺时，首页和独立上传仍然可用，房间与 A 文件返回带中文原因的 503。保存章节编辑后，源 `edits.json` 的字节保持一致。可选桥接的页面、交接脚本、CSS 及素材查询与 V0.6 对照一致。
5. **Edge 复测步骤**。`node tools/test-native-server.mjs --browser` 启动无头静音 Edge，依次打开原生首页、地下城和第 5 章，向空白工程导入海滩房间，再打开使用上传素材的测试工程并下载离线 HTML。本机沙盒完成了 CDP 连接，随后报告 `CDP 連線已關閉`。该次运行没有观测到首屏或点击结果。

## 兼容性决定与边界

- `--data` 默认取工程目录的上一级。两项均省略时使用程序目录旁的 `scene-studio-data/projects/`。新素材写入 `user-assets/`，旧版登记继续只读回退。
- V0.6 使用 v8 目录之外的数据校正房间。只有裸 v8 时仍可导入地图，并在响应中标出缺少的可见性校正。配置配套数据可复现本机完整响应。源发行版缺少 review-009 的生成背景图，其可选扩展保留在 V0.4 布景桥接中。 [配套数据布局](../开发者文档.md#外部数据与兼容)
- 序列导入移植自发布清单锁定的 `sequence_assets.py`，原 SHA-256 为 `3f55126a8828f2860499f6c96164d5dbc5236df34738f0f693ab77daf60e59d7`。游戏进程同步和把素材安装到游戏副本的逻辑不属于原生服务接口。此次未执行需要真实游戏窗口的六项验收。
- 当前 clone 的 `.git` 在沙盒内只读，`git add` 创建 `index.lock` 时被拒绝。交付使用工作区 `.codex-tmp/t1-delivery/` 内从同一基线建立的独立 clone 和同名分支。
