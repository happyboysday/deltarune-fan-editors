# 场景编辑器 V1.0 规划

基线：`release/pure-editor`（4ef04ac），即 V0.6 最新组合（含第 6 章宣传片的赛车、地下城、SOUL、ACT 等全部功能）＋“程序目录不含官方素材”的改动。
V1.0 在分支 `v1.0/main` 上开发，目录 `DeltaruneWorks/编辑器/场景编辑器-V1.0/`。V0.6（`编辑器/场景编辑器/`）保持原样，宣传片工程继续用它。

## 目标

1. **摆脱 V0.4**：不装 V0.4 也能完整运行。V0.4 只作为可选的数据来源和可选的“布景工作台”。
2. **插件扩展**：用户可以用插件添加玩法模式、实体类型、事件动作、编辑器面板和素材；插件可以安装、启用、停用、卸载；离线导出会带上工程用到的插件。赛车和地下城改写成内置插件，证明接口够用。
3. **设置与素材管理**：设置文件＋设置页取代一长串启动参数；首次启动引导；缺哪类素材就关掉哪类功能并说明原因。
4. **整顿与验收**：一键全测；文档合并成使用手册＋开发者文档；版本号统一为 V1.0。

视觉与交互设计（设置页、插件管理页、首次启动引导、整体样式）由 Claude 在功能完成后接手，Codex 只做功能性的最简界面。

## Codex 通用规则

- 只修改自己的工作目录（任务说明里给出）。不要改 `DeltaruneWorks` 下的其他目录：`素材/`、`作品/`、`编辑器/场景编辑器/`（V0.6）、`编辑器/战斗编辑器/` 都只读。
- 不要递归删除任何目录。临时输出一律放在工作目录下的 `.codex-tmp/`（已加入 .gitignore），用完留着即可，Claude 会清理。
- 不要把官方素材（PNG、音频、地图数据）提交进仓库。测试数据从上表的素材目录读取。
- 沿用现有代码风格：紧凑的 ES 模块与 Python；代码注释用英文；用户可见文字用简体中文。
- 前端只做功能性的最简界面，不要重做现有样式（`studio/studio.css`）；视觉设计由 Claude 接手。
- 浏览器测试使用 Microsoft Edge 无头模式并静音（`--mute-audio`），结束后关闭进程和测试服务器。
- 完成时提交到自己的分支（英文提交信息，一个任务可以分几个提交），然后报告：改了哪些文件和接口、运行了哪些测试及结果（命令＋通过/失败/跳过数）、已知问题、没做的事。
