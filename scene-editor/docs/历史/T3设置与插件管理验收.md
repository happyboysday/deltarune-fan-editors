## 接口

以下路径均在现有回环服务上。POST 继承 T1 的 Host、Origin 和 Fetch Metadata 检查。带请求体的示例使用 `Content-Type: application/json`。

| 方法与路径 | 请求示例 | 响应示例，省略部分字段 |
| --- | --- | --- |
| `GET /api/studio/settings` | 无 | `200 {"settings":{"port":{"value":18946,"source":"default","valid":true,"reason":"可用"}},"boundPort":18946,"version":1,"firstRunDone":false,"warning":null}` |
| `POST /api/studio/settings` | `{"settings":{"assets":"D:/素材/场景编辑器素材","port":18947}}` | `200 {"ok":false,"results":{"assets":{"ok":true,"reason":"已保存"},"port":{"ok":false,"reason":"由命令行指定，不能在设置中覆盖"}},"settings":{"assets":{"pending":{"value":"D:\\素材\\场景编辑器素材","source":"settings"}}}}` |
| `GET /api/studio/settings/detect` | 无 | `200 {"results":{"assets":{"value":"D:\\素材\\场景编辑器素材","valid":true,"reason":"已检测到"}}}` |
| `GET /api/studio/capabilities` | 无 | `200 {"capabilities":{"layout":{"label":"布景工作台","available":false,"reason":"未设置目录","settings":["base"],"missingSettings":["base"]}},"warning":null}` |
| `POST /api/studio/restart` | `{}` | `202 {"ok":true,"exitCode":3}`，回应后退出 |
| `GET /api/studio/plugins` | 无 | `200 {"plugins":[{"directory":"fireflies","builtin":false,"base":"/plugins/fireflies/","manifest":{"id":"fireflies"},"errors":[],"enabled":true,"source":"user","projects":[{"id":"demo","title":"萤火小径"}]}]}` |
| `POST /api/studio/plugins/install` | `{"folder":"D:/插件/fireflies"}` 或 `{"zip":"UEsDB..."}` | `201 {"ok":true,"id":"fireflies","enabled":true}`。冲突返回 409，校验失败返回 422 |
| `POST /api/studio/plugins/<id>/enable` 或 `…/disable` | `{}` | `200 {"ok":true,"id":"fireflies","enabled":false}`，此例为停用。内置插件返回 403 |
| `POST /api/studio/plugins/<id>/uninstall` | `{}` | `200 {"ok":true,"id":"fireflies","trash":"D:/数据/plugins-trash/fireflies-20261121T170000000000Z"}` |
| `POST /api/studio/plugin-projects` | `{"tab":"59700993-d899-4e7f-89fd-499d1723b401","project":{"id":"demo","title":"萤火小径","plugins":["fireflies"]}}`，关闭时发 `project:null` | `200 {"ok":true}`，供编辑器登记已打开工程 |

`GET /api/studio/settings` 的路径值采用启动时生效的数据，写入后通过 `pending` 显示下次启动值。路径可用 `null` 恢复默认。插件开关与 `firstRunDone` 保存后立即生效。设置写入返回逐项结果，有效项可在同一请求中保存，引导完成状态需该次提交的所有设置均有效。损坏警告和备份位置由设置与能力接口共同返回。插件静态路由对停用的插件返回 403。

## 兼容性决定与边界

- `--data` 的位置先于设置解析确定。用设置修改 `projects` 只切换工程路径。保留 `DR_ASSETS` 作为未显式配置的后备。可用素材按功能拆开判断，路径校验允许部分场景素材子目录。
- 安装发现相同 ID 就拒绝。卸载保留该 ID 的启用偏好。回收使用目录移动，插件目录与数据目录位于不同卷时会返回错误并保留原目录。手工维护的插件可继续通过 T2 的目录发现加载。
- 工程依赖显示使用当前服务上的编辑器标签页登记。离开页面时清理，异常关闭的记录约两分钟过期。其他标签页通过同源通知、聚焦检查和心跳得知插件停用；打开或应用工程时重新检查依赖。替换过插件的标签页应重新加载，以获取浏览器重新导入的模块。
- T2 插件生命周期和钩子签名保持原有约定。T1 的兼容性扩展包括可选布景初始化失败后降级，以及新增设置和重启路由。快速层中的原生服务回归通过了 41 项 V0.6 响应对照。

## Claude 界面交接

- 首页需要处理带 `data-capability` 的禁用项，包括章节主线、布景工作台、战斗编辑器、三个依赖素材的示例入口、官方房间及物件候选、布景内嵌和存档。原生按钮使用 `disabled`，不可用链接以 `aria-disabled` 标识并移除 `href`。有战斗依赖的工程会按战斗能力禁用试玩、离线导出和战斗校验。章节页按章节分别禁用生成和试玩。
- 设置页区分当前值、来源、下次启动值和逐项错误。引导与设置页复用表单，自动检测先填入表单，用户确认后保存。保留「保存并重启」的确认，操作会影响其他打开的标签页。
- 插件列表显示启用状态、清单错误和相关工程。卸载始终确认，停用被打开工程使用的插件时确认。内置插件只显示状态。插件不可用的当前工程需要保留打开管理页和导出 JSON 草稿的入口。
