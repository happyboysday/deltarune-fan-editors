# DELTARUNE 第 5 章复刻与场景编辑器 V0.6

基于 D:/CodexWorks/DeltaruneWorks/场景编辑器-v0.5 开发独立版本。源证据是本机第 5 章 `data.win`、既有 V0.4 地图/精灵库及 V0.5 拆包样本。Steam 文件、游戏存档、V0.5 和现有创作工程只读。初核房间表含 252 条，粗筛去掉调试、制作模板、占位和明显非地图条目后约 215 条。最终以逐室可审计的纳入/排除表为准。

1. **拆包复习与登记。** 提取房间层、对象实例及变换、对象继承、实例/房间创建顺序、触发相关事件、语言资源和逐条来源。按现实世界、城堡镇、第 5 章暗世界和特殊场景分区。对照 V0.5 已支持的门、触发区、对白、分支、队伍、存档、移动模式和演出指令，逐类列出缺口。游戏专有数据只在用户本机工作目录使用。
2. **以可编辑工程复刻。** 用可复跑的工具生成世界、角色、碰撞、出生口和经原脚本核对的地图连接。为地图就地编排对白、可触发脚本与剧情条件；保留来源引用，分开记录直译、等效实现、近似实现和未移植。多数地图须可进入、走动、触发已核对的对应脚本；单独打开的布景、纯截图和无条件猜测的门不计入。优先覆盖正篇路线和相连支线。对跨地图旗标、一次性事件、重进房间及存档恢复分别处理。
3. **按需求补编辑器。** 从真实脚本缺口中提炼可复用的触发器、事件、角色和渲染能力，使同一场景可在工作台编辑、试跑与复放。新接口加文档、校验和编辑入口；旧工程、戏剧样例及战斗桥保持兼容。复杂机制和外部战斗只在有素材及可验证逻辑时声明完成；不把缺失战斗写成假胜利。
4. **逐层验收。** 提供全章房间/脚本覆盖统计、出处及可追溯的未支持项。目标是超过纳入的主要地图半数（按初筛至少 108 张）都有真实布景、角色和可触发的对应行为，并打通有证据支撑的连续路线。验证所有工程、目标入口和引用；用自动复放及浏览器检查典型房间的走动、交互、跨房间、带条件的事件与存档。交付入口、新工程、复刻工具、差异说明及精简的验收证据。
5. **结束与回收。** 完成交付后只清理本次产生的临时解包、中间图和测试浏览器缓存，优先移入 Windows 回收站，保留可编辑工程、脚本来源索引与复刻工具。若遇到无法跨越的技术阻碍，记录证据和已完成内容，按用户要求暂停目标，不把部分结果报作完成。
