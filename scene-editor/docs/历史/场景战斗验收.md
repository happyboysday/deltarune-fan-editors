# 场景与战斗整合验收

- 从场景界面打开同一工作区的原遭遇编辑器，连续保存两个版本，打包读取到新版本。新建「对白后开战」事件，保存场景，校验遭遇引用；缺文件会指出对应的 `battles.<id>.encounter`。
- Edge 使用真实按键接触开战、逃离、返回；断开 HTTP/HTTPS 后从单文件完成「对白触发→饶恕」、「接触触发→击败」、「接触触发→队伍落败」、「接触触发→逃离」。没有外部资源请求。四条路线保留原房间和触发时坐标，战斗期间场景 tick 不变，结算键未跳过返场对白。
- 每次战斗 BGM 各启动、停止一次。加载中重开会清除挂起战斗，旧战斗不会回写新状态。无头实测落败和逃离后可重新接触，结算只执行一次。
- 新版「灵魂演出试验：靶场与弯道」的自定义心形机制和首领 HUD 随打包保留。原遭遇测试 317 项、流程测试 17 项、旧离线导出测试 25 项通过；旧场景《回声工坊》复放通过。
- 演示 960×756 / 30 fps / 约 32 秒，展示对白→饶恕→档案室与接触→击败两条路线。
