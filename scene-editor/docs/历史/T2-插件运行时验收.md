## 改动位置与 API 一览

| 文件或目录 | 对外接口与职责 |
| --- | --- |
| `studio/plugin-manifest.mjs`、`studio/plugins.mjs` | API 1 清单校验、依赖排序、按工程选择、错误隔离。主接口是 `validateManifest`、`registerPlugin`、`loadPlugins`、`projectPlugins`。 |
| `studio/world.mjs`、`format.mjs`、`view.mjs` | 模式 `enter/step/exit/retry`，确定性 RNG 和通用玩家、镜头、事件上下文。模式、实体及动作的 `validate`，实体 `resolve/step/draw`，动作 `execute`。 |
| `studio/view.mjs`、`resources.mjs` | `drawWorld/drawBackground/drawForeground/drawHud/drawOverlay`、角色与特效钩子。通过 `roomAssets/preload` 收集需要预载和打包的图片。通用的房间图块、动画、视差背景及定时分别在 `room-art.mjs`、`room-backdrop.mjs`、`timing.mjs`。 |
| `studio/editor.mjs`、`index.html`、`grid.mjs` | 选择工程已声明的模式，挂载 `mount/roomPanel/entityPanel`。工具按钮支持校验、撤销和刷新。分层网格通过 `layer/controls/grid` 接入。 |
| `studio/plugins/builtin/{dungeon,kart}/` | 各自拥有清单、运行时、校验和绘制。地下城插件也拥有图层检查器和预设。原模块路径保留 ESM 再导出，便于外部场景工具继续使用。 |
| `studio/player.mjs`、`trailer-script.mjs`、`scene-navigator.mjs`、`campaign.mjs` | 使用模式声明的输入、演练时间线、碰撞盒、调试字段和可用模式。 |
| `studio/plugin-bundle.mjs`、`standalone.mjs`、`tools/export-example.mjs` | `bundleModules(project,read?)` 从播放器及所选插件的入口递归收集模块；`makeHtml` 生成 data URL 与 import map。 |
| `plugins_host.py`、`studio_server.py`、`tools/plugin-files.mjs`、`tools/scene.mjs` | 新参数 `--plugins`，发现接口 `/api/studio/plugins`，静态路由 `/plugins/<id>/…`，以及使用同一清单校验器的 Node 保存校验。T1 可注册 `plugin_routes(directory,node)` 返回的 `plugin_route(method,path,query,body,head_only)`。命中返回 `(status,content_type,bytes)`，未命中返回 `None`，发送响应的适配层处理 HEAD 正文。 |
| `examples/plugins/fireflies/`、`docs/插件开发.md` | 代码绘制的完整示例，包含模式、实体、动作、房间与实体检查器、工具按钮和演练工程。开发文档给出全部钩子的参数和时序。 |
| `tools/test-env.mjs`、`tools/test-all.mjs`、`tools/*plugin*.mjs`、`tools/fixtures/plugin-parity/` | 隔离项目副本和测试服务器，执行状态、画面、发现、保存、导出和浏览器验收。 |

## 兼容决策与交付

- 省略工程 `plugins` 字段时启用两个内置插件。显式列出插件时，只启用列出的插件及依赖，空数组对应基础玩法。旧场景无需修改。
- 运行时钩子同步执行。离线模块使用文件头的静态 ES 导入和再导出。宿主保存通用检查点数据；进入或恢复房间时，插件可以从旗标、库存及实体变化重新建立局部状态。
- 插件的安装、启停、卸载和设置持久化留给 T3。宣传片原工程、官方素材和现有样式表均未改动。
- 当前工作区的 `.git` 受沙盒只读限制，创建 `.git/index.lock` 被拒绝。交付提交位于工作区内 `.codex-tmp/review` 独立克隆的同名分支；增量 Git bundle 为 `.codex-tmp/t2-plugins.bundle`，其基线前置提交为 `cc3a7bb`。
