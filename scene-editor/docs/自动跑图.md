# 在试玩里使用 AI 自动跑图

**正式章节：** 双击 [启动章节工作台](../launch-chapters.cmd)，选择第 4 或第 5 章，点「工作台内试玩」。自己选择存档；看到可行走的角色后，在画面下方打开「AI 自动跑图」。也可以先点地图上的「从本段预演」。

**自己制作的场景：** 双击 [启动场景编辑器](../launch-v1.cmd)，打开工程后点「试玩」或「试当前房间」，在画面下方展开同名面板。这个功能属于编辑器，不会自动加入交给玩家的离线 HTML。

| 想做什么 | 操作 |
|---|---|
| 检查某条路线 | 选「前往指定房间」及目的地，点「开始跑图」。到达后会松开按键 |
| 查不熟悉的地图 | 选「探索未到过的房间」。AI 从当前可用的门开始，必要时折返，优先去没到过的房间 |
| 连续检查主线节点 | 在章节试玩中选「依次前往主线节点」，指定第一站。中途接管后可以「继续原路线」 |
| 阅读或决定剧情 | 章节试玩默认会翻普通台词，在有选项时停下。可以关闭「自动翻对话」，或明确勾选「遇到选项选第一项」 |
| 立即接管 | 点「暂停 / 接管」，或在试玩画面按方向键、触控方向键。界面会保留当前房间。章节试玩还可继续剩余路线 |
| 留下证据 | 章节试玩点「导出本次按键与路线」。保存文件含本次启动的房间、剧情值、按键、按键来源、寻路决定、实际试玩文件指纹，并区分正常存档与段落预演 |

AI 在本机运行，不依赖联网模型。它从实际位置出发，沿普通输入路径走路、交互、起跳。正式章节中，跨房计划读取编辑工程，当前房间的门和碰撞采用游戏实际运行结果。楼梯口等双向入口会被单独避开。横版使用脚下和前方是否有地面判断起跳，并在空中决定何时悬停。修改地图后重新生成试玩即可使用新布局。

**支持边界。** 单独「前往指定房间」只检查是否进房；「依次前往主线节点」的部分节点还会等待剧情值、踩中原作命名触发区或主动与摊位互动。战斗、需要推断的剧情谜题、专用控制角色，以及工程里无法确定去向的脚本门，可能需要手动通过。普通场景试玩也会把剧情选择、节奏挑战和存档确认交给玩家。封路、长时间原地不动或多次落坑会停止，避免在同一处无限试错。

- 第 5 章家到城堡镇，见 `第5章_自动跑图到城堡镇.json`。从剧情值 5 的卧室预演起步，开启自动选择第一项后通过早餐、院子、小镇三条街、学校和暗门，共 12 个房间。

- 第 5 章悬崖冲刺，见 `第5章_自动跑图悬崖左入口.json` 和 `AI自动跑图_悬崖实录.mp4`。从左入口 x≈19 起步，越过三处长断层，进入 Seth 的房间。
- 第 4 章小镇北街到南街，见 `第4章_自动跑图.json`。从北街经过中街到达南街。
- 普通自制场景在浏览器中验证了接管、暂停与绕过障碍跨房。章节试玩画面见 `自动跑图_工作台.png`。

## 从其他创作工具使用

本机工作台已启动试玩后，通过 `GET /api/studio/chapters/{4或5}/route` 读取当前启动的 `pid`。向同章的 `navigator` 端点 POST 下列 JSON，随后 GET 同一端点可读取 `state`、`note`、`room`、`route` 和 `visited`。所有控制命令必须带本次的 PID。

```json
{"pid":12345,"command":"start","mode":"target","goals":["room_dw_castle_town"],"dialogue":true,"firstChoice":false}
```

`mode` 也可用 `explore` 或 `route`（依次使用 `goals`）。`command: "stop"` 暂停，`command: "resume"` 从当前位置继续。只把 `state: "arrived"` 当成到达目的地；`needsHelp` 表示需要接管，`explored` 表示当前已知可达出口走完。读取 `record` 端点可取得整场记录，`keys` 与 `inputSources` 一一对应。

主线节点也可以写成对象。例如 `{"room":"room_dw_garden_meetflowery","trigger":"cutscene","plotAtLeast":210}` 会在实际触发区域中寻找能走到的位置，直到剧情达到 210；`{"room":"room_town_mid","point":[1090,131],"interact":true,"plotAtLeast":150}` 会走近并按互动键。同一节点启动的演出在换房后才写入剧情值，也会被正确识别。普通字符串目标仍只要求抵达房间。

章节跑图会识别服装编辑菜单和北街需要持续按方向的演出。关闭「遇到选项选第一项」会把服装菜单交给玩家；开启时保留当前搭配、选择 END 并确认。二维冲刺会读前方水面、碰撞和可选车道，攀壁拆分成需要人工接管的玩法，避免被误报为一直在播演出。多层横版遇到同侧不同出口时会提示所在楼层。当 GameMaker 弹出 Code Error，工作台会读取本次游戏进程的具体错误，不会自动忽略。
