# 更新日志

## V1.0

相对 V0.6 的发布变化。

### 新增

- 场景编辑器使用原生 Python 服务，可以直接导入房间、解析素材、管理自定义图片和动画序列。
- 插件 API 1 支持房间模式、实体、事件动作、编辑器面板和素材。内置伪 3D 赛车与地下城使用这套接口，附带可安装的「萤火小径」示例。
- 设置页、首次启动引导、目录自动检测和能力报告。插件管理支持从文件夹或 ZIP 安装、启用、停用和卸载。
- 新增使用手册、开发者文档、统一测试入口和带 SHA-256 清单的发布打包脚本。

### 变更

- 以 `launch-v1.cmd` 为主入口，用「保存并重启」切换路径或端口。功能按素材和工具的可用性启用。
- 离线 HTML 会打包工程选择的插件和相应模块。旧发布文件可独立运行，需要新格式时从工程重新导出。
- 新上传、设置、缓存、章节试玩副本和默认战斗工作区使用可写数据目录。发布 ZIP 包含程序、文档和自带示例，官方素材由用户另行配置。

### 兼容性

- 继续读取 `deltarune-scene/1` 工程、`director-map/1` 布景以及旧自定义素材登记。旧工程省略 `plugins` 时默认启用内置插件。
- V0.4 可作为布景工作台和只读数据来源。旧版启动文件继续转发到新入口，章节入口保留端口 18947。
- 兼容的战斗编辑器可继续用于场景接线。仅新版战斗编辑器提供的样例会在缺失时跳过相应验收子项。

### 已知问题

- 完整第 4、5 章依赖 Windows 本机游戏运行环境。离线 HTML 面向网页场景工程。
- 用不同卷上的插件目录与数据目录时，卸载可能因回收区移动失败而保留原插件。
- Windows 沙盒中的 Edge 可能在 CDP 连接阶段中断，浏览器验收的实际执行结果见测试基线。 [V1.0 测试基线](docs/V1.0测试基线.md)
