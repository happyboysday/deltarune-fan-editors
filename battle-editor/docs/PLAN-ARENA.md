# 战斗区域扩展规划

目标是让同一套弹幕、回合和录制工具支持真正的无框躲避、异形房间和局部裁剪。继续使用现有的 640×480 逻辑坐标、红心规则和工程格式。

| 组成 | 本次交付 |
| --- | --- |
| 玩家活动区 | 每段攻击可选择随原战斗框、覆盖战斗舞台（不含下方 HUD）、或自定义简单多边形。多边形可以内凹，心形判定圆不会穿墙，沿边移动时可滑动。错误轮廓在编辑器里标明；导入错误数据时退回矩形，正常工程不用修改。 |
| 可见外观 | 原战斗框可选传统样式、只画边线或完全隐藏；异形活动区可以独立显示边线。这些选项只改变画面。 |
| 弹幕裁剪 | 每种子弹可选不裁剪、按原战斗框、按活动区、或按一套独立的多边形裁剪。渲染与命中沿用同一裁剪区域；装饰弹仍可选择不参与碰撞。 |
| 编辑与验证 | 在攻击检查器中编辑两套轮廓、检查合法性、预览活动边界。两套轮廓都使用舞台坐标；可通过在遭遇里串联攻击切换场地。保留现有弹幕预览、自动躲避、轨迹和离线导出入口。 |
| 示例 | 提供可编辑、可试玩的无框与异形裁剪示例，以便在预览里直接比较效果。 |

验收以实际输入和画面为准：无框模式要能走出旧矩形；凹角要挡住灵魂，移动时不能跨过凹口；局部裁剪要能和活动区采用不同边界；关闭框线不能改变活动范围。例子从便携版打开并导出为离线 HTML 后，规则要一致。原木偶工程和已归档的定稿保持不变，旧版攻击文件继续按原规则运行。

本阶段不新增黄心射击、方向格挡、轨道移动、实时透视相机或 3D 碰撞。预制逐帧的伪 3D 仍可作为现有 2D 素材使用；将来若需要随玩家实时变化的纵深，再单独设计镜头和投影。
