# 戰鬥版面規格（依實機畫面量測）

來源：使用者提供的 DELTARUNE Boss 戰速通錄影（簡中補丁，1920×1080；遊戲區 x 160–1759 × y 0–1079，水平被拉伸 1.11 倍）。
量測方法：裁出遊戲區並縮回 **640×480**，以下全部是**遊戲邏輯座標**（誤差約 ±3px）。參考幀在 `docs/reference-frames/`（不進 git，可直接開來看）。

## 1. 分區

```
y   0 ┌──────────────────────────────────────────────┐
      │ TP 條   隊員縱列（左）     戰鬥框（中）   敵人（右）  │  ← 戰場（背景鋪滿 0–362）
y 362 ├──────────────────────────────────────────────┤  ← 細分隔線（灰）
      │ 隊伍面板列（y 365–400，每人一格）                       │
y 402 ├──────────────────────────────────────────────┤  ← 細分隔線
      │ 底部文字區 y 405–480：旁白 / 對話+頭像 / 選單清單 / FIGHT 攻擊條 │
y 480 └──────────────────────────────────────────────┘
```

- **背景只畫在 0–362**；362 以下一律純黑。
- 戰場上**沒有**浮在中間的文字框；所有旁白、對話、選單清單、FIGHT 條都在**底部文字區**。

## 2. TP 條（左上）

- 直立條：外框 x 40–60、y 50–258（寬 ~20、高 ~208），深紅底；橙色填充由下往上（TP%）。頂端斜切。
- 標籤在條的左側：「T」「P」上下排列（x 8–28、y 85–115），其下為數字（如 `16`）與 `%`，字為白色粗體點陣。
- TP=100：標籤改為黃色直排「MAX」，條為黃色。

## 3. 隊員（左側縱列）

- 精靈放大 2 倍，**以腳底為錨點**，以 x=128 為縱列中心（各人錯開 8px），在 TP 條右側留出空間。
- 腳底 y：
  - 1 人：240
  - 2 人：190、298
  - 3 人：140、230、322
  - 4 人：120、190、260、330
- 已選行動的隊員本身播對應動畫（防禦舉盾、魔法施法…）。

## 4. 敵人（右側）

- 中心 x 約 470–540，腳底 y 約 240–300；多隻時上下錯開（例：2 隻 (480,200)/(530,290)）。
- 受擊：橫向抖動 + 傷害數字。

## 5. 戰鬥框

- 預設（最常見）：外框 **x 246–396、y 107–272** → 中心 **(321, 190)**，外框約 **150×165**，綠色描邊約 3px，黑色填充。
- **框畫在敵人之上**（敵人會被框遮住）。
- 出現/消失：從中心旋轉+縮放展開（約 8–10 幀），不是從隊伍處飛出。
- 每個攻擊可自訂大小（例：高框 y 125–333）。

## 6. 隊伍面板列（y 365–400）

- 寬 640 平分成 N 格（3 人時每格 ~213；2 人時兩格靠中間，例 x 107–318、x 340–555）。
- 每格一行：**頭像小圖示**（x+14，16×16 放大 2 倍）→ 名字（大寫，fnt_main 放大，x+48）→ 小字「HP」→ 右側 `90/ 90` → 數字下方 HP 條（x+128 到 x+205，高 ~8，填角色色）。
- 角色色：Kris 青 `#00ffff`、Susie 洋紅 `#ff00ff`、Ralsei 綠 `#00ff00`、Noelle 黃 `#ffff00`。
- 選擇、結算和躲避時都保留隊員頭像。指令圖示顯示在指令列。

### 選單中（輪到某隊員選擇）

- 該隊員的面板**整格上移約 35px**（y 327–400），以角色色描邊（~2px）。
- 上半：頭像+名字+HP（同一般列）；下半：**5 個按鈕**一排（FIGHT / ACT（或 MAGIC）/ ITEM / SPARE / DEFEND），每個約 30×26，x 從格左 +13 起、間距 ~36，y 370–397。
- 選中的按鈕高亮（黃），按鈕下方顯示小字中文標籤（如「行动」「魔法」）。
- 其他隊員面板維持在一般位置。升起面板畫在舞台分隔線上層。

## 7. 底部文字區（y 405–480）

字體：**fnt_mainbig**（中文用 `fnt_mainbig@zh`），一行高約 32px；文字白色。

- **旁白（flavor）**：`* ` 開頭，x 30 起，最多 2 行（第 2 行縮排對齊 `* ` 之後，約 x 58）。選單時顯示在此處。
- **對話（say，帶頭像）**：頭像放在 x 20–112 的區域內，按可用寬高縮放，完整顯示，文字 `* ` 從 x 145 起，續行 x 175。
- **選單清單**：紅心游標（x 30），項目 x 55 起；
  - 敵人清單：每行一隻（行高 ~32）：名字、狀態小字（如「（睡着）」「（疲惫）」，青色/灰）、右側 x 510–590 兩條小條（HP、MERCY）。
  - ACT/法術/道具清單：**兩欄**（x 55 與 x 330），每欄每頁 3 行；需要其他隊員協助的 ACT 在名稱前顯示第一位協作者的小頭像。右側可顯示說明/TP 消耗（灰字）。
- **FIGHT 攻擊條**：每位出手的隊員一列（從 y 405 起）：左邊隊員頭像（x 10–40）＋小字「按下」；目標框外框 x 80–203（左下角連接隊員色粗線，判定點固定在左緣）。白色豎線標記與殘影從右側（x ~380）向左移動，高度對齊目標框內部；判定文字顯示於框中央。

## 8. 敵人台詞泡泡

- **白色圓角矩形**，**位於敵人左側**，尾巴（小三角）指向敵人；黑色文字（小字 `fnt_dotumche` / 中文 `fnt_dotumche@zh`，約 12px 行高）。
- 多個說話者 → 多個泡泡同時出現，各自貼在說話者旁（高度對齊說話者頭部）。
- 時機：行動結算完 → 泡泡出現（可按 Z 跳過）→ 泡泡消失 → 戰鬥框展開 → 彈幕。

## 9. 傷害數字

- 出現在敵人身體右側，**多位隊員的數字由上往下堆疊**（行距 ~20），顏色 = 出手隊員色；字為粗體點陣數字（可用 sprite 字或 fnt_mainbig 放大）。
- 先往上彈一下再停住，約 1 秒後淡出。MISS 為灰色。

## 10. 流程節奏（觀察）

1. 選單：底部旁白 + 當前隊員面板升起。
2. 全員選完 → 面板帶著原頭像回位。
3. 結算：ACT 文字/對話依序在底部文字區（帶頭像）；FIGHT 條在底部文字區。
4. 敵人泡泡 → 框展開 → 彈幕（底部文字區清空）。
5. 框收回 → 回到選單（下一回合旁白）。
6. 勝利或全員饒恕：終局掛鉤後，底部文字區顯示一般勝利旁白。確認後停在最後一幀。
