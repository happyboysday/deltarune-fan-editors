## 1. 作品概要

### 1.1 遭遇檔：`encounters/rt-lanternmoth.json`

- 敵人：**Lanternmoth**（燈蛾），HP/最大 HP 150、ATK 6、DEF 0、`spareAt: 100`，外觀用既有素材 `spr_yellow_butterfly` 放大 1.8 倍
- 回合：3 回合（`turnOrder: "loop-last"`）
  - 第 1 回合攻擊 `rt-lantern-drift`、第 2 回合 `rt-lantern-spiral`、第 3 回合回到 `rt-lantern-drift`
- ACT（3 個，都可用滑鼠點）：
  - `Check`：顯示 ATK/DEF 與一段中文描述
  - `Sing`（mercy +22）：給 Kris 的 ACT，跑一段 say/bubble cue，並 `set var.sang += 1`
  - `Shelter`（mercy +22）：給 Susie 的 ACT，**若 `var.sang >= 1` 再額外 +10 mercy**（用 `if` cue 做跨回合連動）
- 其他：`items` 有 `darkburger`（heal 70 ×2）與 `manual`；`hooks` 寫了 intro / victory / spared / defeat / flee；`vars.sang` 初值 0
- 隊伍：Kris 90 / Susie 110 / Ralsei 70，Ralsei 多一個法術 `pacify`（TP 20、mercy +20）

### 1.2 兩個自創攻擊

| 檔案 | 名稱 | 長度 | 設計 |
|---|---|---|---|
| `attacks/rt-lantern-drift.json` | 灯蛾余烬 | 6.5s | 左右半「余烬雨」（中央刻意留缺口）＋ 左右翼各 3 發橫掃 ＋ 上下各 4 發對夾；子彈 `ember` 用自繪 sprite、`mote` 用內建 `spr_smallbullet` 染色 |
| `attacks/rt-lantern-spiral.json` | 灯火回旋 | 7.0s | 光點螺旋（`angle = i*43 + t*70`）＋ 左右正弦掃射（`pathY = sin(age*150 + i*55)*32`）＋ 戰鬥框由 150×165 收窄到 128×144 再復原（`quadInOut` / `sineInOut` 0.8s） |

兩支都遵守 `docs/AGENT-GUIDE.md` 的風格建議：640×480、30FPS、角度 0=右 90=下、子彈從框外生成、`maskToBox` 關閉、留安全路線、4–10 秒。

### 1.3 自繪子彈素材

- 兩張圖都實際出現在攻擊裡（`play.html` 實跑時畫面上的 ember 就是這張自繪 PNG）

### 1.4 demo 演示腳本

## 4. 不方便 / 可優化（依影響排序）

1. **結構樹的操作鈕**（B1）：hover 才出現、出現就壓縮 label 並佔住列中央；建議 `position:absolute; right:0` 浮在列尾，或改成選取後在 inspector 操作；✕ 刪除要確認。
2. **存檔對話框**（B2/B6）：Enter 不送出 ＋ 非法檔名靜默改寫；建議 input 即時驗證（紅字）+ Enter 觸發主按鈕。
3. **時間軸高度**（B3）：預設容不下 8 軌；建議記住面板高度、或預設至少 8 軌高、或加「↕ 可捲動」提示。**繞路是拖 5px 高的 `#split-timeline` 往上**（實測拖 220px 後 wrap 148→368，8 軌全可見），但這條路幾乎不可能自己發現——建議 splitter 加把手圖示或 hover 高亮。
4. **時間軸文案**（B5）：「double-click = add」與實際（只有空白軌才開）不符，改成「在空白軌道雙擊」。
5. **`#toolbar-msg` 不會自動清除**：載入範例後 "Loaded sample spade-rain" 一直掛著，後續操作容易誤判成功；建議 3–5 秒淡出。
6. **inspector 的「目前選取」不明確**：載入範例後 `#selection-label` 空白、inspector 停在 "Round settings"（攻擊編輯器），看起來像選中卻不是。建議標題加 `（未選取）`。
7. **demo 路徑編輯**：只能在 640×480 預覽上用滑鼠拖點（SVG `dr-demo-point` / `dr-demo-target`），沒有數值表格（t/x/y/slow）、不能鍵盤微調；建議加表格模式，或至少顯示當前點的數字。
8. **範例載入後沒有檔名**：`editor/fileops.js:869-876` 開範例後 `afterOpen(..., null)` → 第一次 Save 一定跳 Save as；建議帶入範例檔名或提示「這是範例，儲存會另存」。
9. **事件新增選單位置**（B9）：固定貼在 timeline 上緣遮住內容；建議以點擊點為錨、優先往上開。
10. **`encounter.html` 預覽 canvas 是 624×468**（640×480 的 0.975 倍）：非整數縮放讓像素邊緣模糊，點預覽座標與遊戲座標有換算誤差；建議整數縮放。
11. **`chrome=0` 連狀態列一起隱藏**：測 autoplay 時看不到 `#auto-status`；建議只藏裝飾、保留可選狀態。
12. **`#btn-try` 是頁內切換試玩模式**（不是跳 play.html）：第一次用會愣一下，建議 toast 說明或改文案「在頁內試玩」。
13. **素材面板沒有「我的自訂素材」分區**：新增的 `custom: true` 條目與 2786 筆混在一起，只能靠搜尋；建議頂部加 Custom 篩選。
